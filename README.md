# Reviza Baileys

Pustaka WhatsApp berbasis Baileys untuk kebutuhan bot dan aplikasi **Reviza**.

## Nama Paket

`@reviza/baileys`

## Instalasi

```bash
npm install @reviza/baileys
```

Untuk memasang langsung dari repositori GitHub:

```bash
npm install github:revizahoshii-no/reviza-baileys
```

Ganti `revizahoshii-no` dengan nama akun atau organisasi GitHub milik Reviza.

## Penggunaan

Gunakan API yang tersedia pada source paket sesuai kebutuhan aplikasi.

Contoh:

```js
import makeWASocket from "@reviza/baileys";
```

## Pengembangan

```bash
git clone https://github.com/revizahoshii-no/reviza-baileys.git
cd reviza-baileys
npm install
```
